# Private potential-statue research

Researched on 17 November 2026. These files support private owner research; they are not approved public website or Instagram wording.

`london-47-original.csv` is an unchanged copy of the owner's CSV. `london-stories.json` records the sourced story findings for each numbered CSV row. `src/lib/server/potential-suggestions.json` combines those 47 rows with the initial worldwide research, preserving original names, addresses, Maps URLs, coordinate values, notes and provenance. Seven matching London records reuse the original suggestion IDs: Brown Dog, Trump, Blind Beggar, Animals in War, Grosvenor's dogs, Dog in a Kennel and Paparazzi Dogs. The result is 55 entries, including one archived historical entry. Separate installations of the same heraldic subject and separate miniatures at one address are retained.

Story links are stored in each record's notes and primary source field. The artist's individual narratives for the Little Things miniatures are fictional scenes involving Dogman and Rabbitwoman, not biographies of real dogs. The installed objects and exact pins still need checking. A Little Recycle has a sourced trail-level story; an individual narrative was not established. Gunnersbury's maker and date remain unresolved. Giro is a grave marker, not a dog statue. Geoffrey Barkington is archived because the memorial is listed as lost. Wild Kingston was advertised until September 2026, so Rise Up Rhino's continued presence needs confirmation. Museum display and admission arrangements should be checked before visiting.

After applying migration 007 and deploying the application, open **Owner area → Potential future dog statues → Researched suggestions → Add researched suggestions**. This inserts the records into the private catalogue. Repeating the import adds only missing stable IDs and preserves edits and archive choices. Choose **All** in the status filter to include archived records. This is a curated starter dataset, not a general CSV upload feature.

Edit notes, source links, map links and coordinates in the private editor and save explicitly. Search includes the original CSV IDs and notes. None of these records creates a public statue page or Instagram post. Write and approve any eventual public story separately in the main statue editor.

## Embedded map locations

`src/lib/server/potential-map-locations.json` stores 50 approximate map fallbacks, checked on 17 November 2026. Each includes its source URL and original address/city/country. UK postcode centres and broader postcode-area centres were looked up once using [Postcodes.io](https://postcodes.io/docs/); other researched coordinates cite their individual sources. A broad area marker can be a substantial distance from the sculpture and is explicitly labelled as such. These are planning aids, not independently verified sculpture pins. The five original saved coordinate pairs remain unchanged. Several entries share a museum, postcode or area, so a numbered marker may contain multiple records. Saved coordinates override these fallbacks; changing an address invalidates its fallback. No private notes or addresses are sent to a geocoder when using the app.

## Image research

Five GPT-6.1 Terra researchers, with low reasoning as approved by the owner, researched 11 records each. Their source findings are retained in `potential-images-1.json` through `potential-images-5.json`. The final combined import dataset is `src/lib/server/potential-image-suggestions.json`: 55 entries with one reference image each. The parent reviewed gaps, resolved missing artist images, checked source matches and recorded direct image HTTP responses in `image-link-verification.json`. The final check retrieved image responses for 54 links; the Moat Bridge Commons image was identified on its source page but temporarily returned HTTP 429. Online availability is not guaranteed.

Credits and licence statements are retained where established; unestablished permission is explicitly recorded. Several artist images are product/edition references rather than photographs of the current London installation. Gunnersbury uses a labelled 3D model render, visually compared by the researcher to the council's wooden-dog photograph. The Queen Mother image shows the relief, and Geoffrey Barkington is a historical reference. Source metadata and uncertainty notes must be reviewed before public reuse. No new public wording or public photo permissions are approved by this research.

The app stores links and provenance in the private database. It does not download external image files into its media storage. An owner import appends missing links without replacing their existing image selection; links can be removed or reordered in the editor. To archive the image binaries in future, add a deliberate rights-reviewed download workflow rather than treating these links as a permanent image backup.
