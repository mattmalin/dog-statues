# Public wording

The owner writes the public wording for Dog Statue Atlas. Preserve their wording exactly unless they supply a replacement or approve a specific proposed change. For features that need new wording, use an existing approved label where it fits and list any missing text for the owner to write. Keep proposed AI wording in the review conversation until approved.

Keep shared public wording in `src/lib/public-copy.json`. Include visible labels, empty and error states, metadata, accessibility text, and RSS copy when reviewing changes. Statue names, summaries, descriptions, photo alt text, and credits belong in the owner editor. Website copy reused for Instagram requires the same review.

Before committing a change to public wording, show the owner the exact old and new wording, where it appears, and any places it is reused. Owner-supplied wording may be committed verbatim. Keep changes to public wording in a separate commit when practical. A general request to build or deploy a feature does not approve new wording. Verify the words on the affected pages or previews before release. Follow `PUBLIC-COPY.md`.
